# Simuladores de Micrômetro

Quatro simuladores Flash originais do Professor Eduardo Stefanelli, com menu em português e reprodução por Ruffle 0.7.1. Sistemas métrico e inglês conforme os materiais de origem.

Os SWFs foram extraídos dos quatro projetores Windows sem executar os EXEs. Foram validados descompressão, tamanho declarado, limites dos registros e registro End. Os dois arquivos de origem chamados simulador3.exe possuem conteúdos diferentes. Nenhum EXE está publicado.

## Uso

Abra index.html por GitHub Pages ou servidor HTTP. Abrir diretamente por file:// pode impedir o carregamento. Todos os arquivos Ruffle ficam na raiz junto das páginas. As licenças do Ruffle estão preservadas em LICENSE_APACHE e LICENSE_MIT; elas não concedem licença sobre os simuladores originais.

Autor dos simuladores: https://www.stefanelli.eng.br/
Ruffle oficial: https://ruffle.rs/downloads

A compatibilidade visual e dos controles deve ser conferida em cada versão. O conteúdo Flash tem acesso a scripts, rede e abertura de URLs bloqueado pela configuração do player.
